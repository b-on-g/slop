# Слопометр

Считает индекс AI-слопа в русском тексте. Вставляешь текст (можно прямо с Markdown-разметкой) — сразу видишь итоговый индекс от 0.00 до 1.00, вердикт (человек / пополам / нейросеть) и разбивку по метрикам с полосками. Кнопки нет, всё пересчитывается пока печатаешь. Никуда ничего не отправляется: весь разбор происходит в браузере.

**[Открыть](https://b-on-g.github.io/slop/)** · **[Исходники](https://github.com/b-on-g/slop)**

## Метрики

Набор и формулы взяты из статьи [«Индекс AI-слопа»](https://habr.com/ru/articles/1063010) — но только детерминированная, структурная часть:

- **Длинные тире** — доля абзацев с `—`
- **Абзацы в одну строку** — доля коротких однопредложенческих абзацев
- **Заголовки под копирку** — одинаковая длина заголовков плюс обещание драмы в формулировках
- **Слова-прокладки** — «по сути», «казалось бы», «на самом деле» и компания, на 1000 слов
- **Перечисления по три** — триады в тексте и списки ровно из трёх пунктов
- **Псевдооткровенность** — «честно говоря», «без воды», «спойлер»

Семантические метрики из статьи (антитезы, афоризмы, ссылки на «многих», угасание конкретики к концу текста) здесь не считаются: для них нужна модель, читающая смысл абзацев, а её в браузерном расширении нет. Итоговая формула та же, что в оригинале, только сумма весов в знаменателе перенормирована на шесть фактически посчитанных метрик.

Порт с Python сверен с оригиналом на четырнадцати реальных статьях: `paras`, `tier`, `final` и все шесть метрик совпадают до 1e-9.

## Расширение для Chrome

Собранная папка — она же распакованное расширение (Manifest V3, попап без единого permission):

1. Собрать модуль: `npx mam bog/slop` из корня [MAM](https://github.com/hyoo-ru/mam)
2. `chrome://extensions` → включить Developer mode
3. **Load unpacked** → выбрать `bog/slop/-/`

Клик по иконке открывает тот же интерфейс в попапе.

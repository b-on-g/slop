# Слопометр

Считает индекс AI-слопа в русском тексте. Вставляешь текст (можно прямо с Markdown-разметкой) — сразу видишь итоговый индекс от 0.00 до 1.00, вердикт (человек / слоп с примесью человека / чистый слоп) и разбивку по метрикам с полосками. Кнопки нет, всё пересчитывается пока печатаешь.

**[Открыть](https://b-on-g.github.io/slop/)** · **[Исходники](https://github.com/b-on-g/slop)**

## Метрики

Набор и формулы взяты из статьи [«Невыносимая слопность бытия»](https://habr.com/ru/articles/1063010). Шесть метрик считаются прямо в браузере, по одной только разметке текста:

- **Длинные тире** — доля абзацев с `—`
- **Абзацы в одну строку** — доля коротких однопредложенческих абзацев
- **Заголовки под копирку** — одинаковая длина заголовков плюс обещание драмы в формулировках
- **Слова-прокладки** — «по сути», «казалось бы», «на самом деле» и компания, на 1000 слов
- **Перечисления по три** — триады в тексте и списки ровно из трёх пунктов
- **Псевдооткровенность** — «честно говоря», «без воды», «спойлер»

Остальные четыре метрики требуют модели, читающей смысл абзацев:

- **Антитезы «не X, а Y»** — самый тяжёлый из паттернов после тренда конкретики
- **Афористичные концовки** — абзац закругляется цитируемой фразой-выводом
- **Ссылки на «многих»** — «исследования показывают» без имени, источника и цифры
- **Конкретика тает к концу** — наклон линейной регрессии по оценкам плотности фактов, вес 1.5

Псевдооткровенность в оригинале тоже семантическая. Без модели она считается грубой эвристикой по маркерам, с моделью её размечает модель.

Итоговая формула из статьи такая, что метрика с нулевым счётом не попадает ни в числитель, ни в знаменатель, так что выключенная семантика итог не размывает.

## Два отступления от статьи

Оба про знаменатель долей, и оба нашлись на живом телеграм-посте, который на глаз слоповый, а по индексу выходил в человека с 0.23.

**Код без ```-ограждений в абзацы не попадает.** Оригинал выкидывает только огороженные блоки, а из телеграма и чатов код прилетает голым. В том посте пять «абзацев» из двадцати двух были shell и TypeScript: они разбавляли знаменатель каждой доли на четверть и в одиночку держали вердикт. Блок считается кодом, когда больше половины его строк выглядят кодом — заканчиваются на `;{}`, начинаются с `import`/`const`/`export`, несут флаг вида `-o` или перенос строки обратным слэшем. На русской прозе шаблоны не срабатывают в принципе: `\w` в JS про ASCII, до кириллицы они не дотягиваются. На README этого репозитория и на самой статье с её питоном ложных срабатываний ноль, а из статьи выкинулось ровно 27 блоков кода.

**Доля паттерна считается по прочитанному.** Абзац короче шести слов модели не отдаётся, но в оригинале остаётся в знаменателе и учитывается как «паттерна тут нет». А это ровно те рубленые реплики, где слоп слышнее всего: «Такие дела», «А потом случилось смешное». Теперь доля делится на число абзацев, которые модель действительно прочитала.

На том посте это дало 0.23 «человек» → 0.57 «слоп с примесью человека», обе цифры закреплены тестами в `metrics/metrics.test.ts`.

## Разбор моделью

Тумблер «С моделью» в шапке включает четыре семантические метрики. Абзацы уходят пачками по десять в [OpenRouter](https://openrouter.ai/), на модели с суффиксом `:free`, промпт взят из статьи дословно. Запрос стартует сам, через полторы секунды после того, как перестаёшь печатать; успел набрать дальше — ответ на прежний текст просто выбрасывается.

Выбранная в списке модель идёт первой, остальные за ней запасными. Это не украшение: у бесплатных моделей пул провайдера общий на всех, и `429 upstream_429` или `502` прилетают в обычный будний день. Упёрлись — идём к следующей модели, в строке статуса написано, кто ответил на самом деле.

Ключ нужен свой, взять на [openrouter.ai/keys](https://openrouter.ai/keys). Приложение кладёт его в `localStorage` и отправляет только в OpenRouter. Пул ключей можно зашить в сборку — массив `$bog_slop_model_keys` в `model/model.ts`.

Денег на балансе не надо, `:free` не тратят кредиты. Но пока за аккаунт не заплачено 10 долларов за всё время, действует потолок в 50 запросов в сутки на бесплатные модели (после — 1000); в минуту в обоих случаях 20. Пачка по десять абзацев означает, что статья на сотню абзацев съедает десяток запросов из этих пятидесяти.

С выключенным тумблером не отправляется никуда ничего: весь разбор происходит в браузере.

## Расширение для Chrome

Собранная папка — она же распакованное расширение (Manifest V3, попап без единого permission).

Проще всего взять готовую сборку — это ветка `gh-pages`, та самая, что раздаётся на Pages:

```sh
git clone -b gh-pages --depth 1 https://github.com/b-on-g/slop.git slop-ext
```

Дальше `chrome://extensions` → включить Developer mode → **Load unpacked** → выбрать папку `slop-ext`. Клик по иконке открывает тот же интерфейс в попапе.

Если собираешь из исходников: `npx mam bog/slop` из корня [MAM](https://github.com/hyoo-ru/mam), расширение окажется в `bog/slop/-/`.
